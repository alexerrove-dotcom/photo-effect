# Cat vs Dogs: War Zone — cloud Android prototype

Isolated Godot 4.5 project used to build the Android APK in GitHub Actions without the user's PC.

Features in this prototype: 5v5 cats vs dogs, five visual variants per side, first-person mobile controls, bots, round score, C4 sites A/B, plant/defuse flow, smoke grenade, reload/aim/crouch controls, health/armor/ammo HUD, minimap, procedural desert-city arena, hitscan combat and simple VFX.

The cinematic image shown in chat is a target concept, not a literal screenshot from this build. This project uses procedural geometry so it can be built entirely in the cloud without third-party proprietary game assets.
