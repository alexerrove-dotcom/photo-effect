Как удалить фон с фотографии

Загрузите изображение, нажмите «Удалить фон» и дождитесь завершения обработки. После этого появится вертикальный разделитель. Слева будет исходное изображение, справа — результат с удалённым фоном.

Перемещайте разделитель мышью или пальцем, чтобы сравнить результат обработки.

1. Загрузите фото

Выберите фотографию с компьютера или телефона.

2. Удалите фон

Нажмите кнопку удаления фона и дождитесь обработки.

3. Скачайте PNG

Результат сохраняется в формате PNG с прозрачным фоном.

Удаление фона онлайн

Photo Effect — простой онлайн-сервис для обработки изображений. Фотография обрабатывается непосредственно в браузере пользователя.

После обработки можно сравнить исходную фотографию с результатом с помощью вертикального разделителя.

Частые вопросы

Как работает сравнение До / После?

Используется один Canvas. Слева показывается исходная фотография, справа — обработанный результат с прозрачным фоном.

Можно ли двигать ползунок пальцем?

Да. Ползунок работает мышью и пальцем.

Сохраняется ли разрешение фотографии?

Исходное фото не уменьшается при загрузке. Результат скачивается непосредственно из готового PNG.

В каком формате скачивается результат?

PNG с прозрачным фоном.

Нужно ли устанавливать программу?

Нет. Инструмент работает непосредственно в браузере.

Конфиденциальность

Выбранное изображение обрабатывается в браузере пользователя. Сервис не предоставляет отдельной формы для постоянного хранения загруженных фотографий.
